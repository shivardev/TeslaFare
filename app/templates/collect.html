Price collector

Open a station on Tesla's site and the TeslaFare userscript saves the price it shows you. Stations on recently planned routes come first. A price stays fresh for 24 hours, then returns to this list.

Collection is off on this server. Set COLLECTOR_KEY (any long secret) and restart.

One-time setup
  1. Install Tampermonkey or Violentmonkey in the browser you'll collect with.
  2. Install the userscript: collector.user.js (your manager offers to install it).
  3. Open any station below. The first time, the script asks for your collector key, the COLLECTOR_KEY value on this server.
  4. A green "TeslaFare: saved…" note appears on Tesla's page when a price is saved, and the station leaves this list.
